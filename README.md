#### Behavioral UX Analysis of Pricing Integration:

1. **The 10% Annual Savings Hook:** Displaying the crossed-out original price (e.g., ~~$348~~ $\rightarrow$ **$313/yr**) triggers **Price Anchoring**, nudging customers to pay upfront for the full year to increase cash flow and lock in long-term loyalty.
2. **"Most Popular" Middle Card:** Placing the **$29/mo Premium Plan** in the center with dynamic highlighting takes advantage of the **Center Stage Effect**, maximizing Average Order Value (AOV).
3. **Emergency Fee Waiver as Incentive:** For Tampa residents dealing with frequent summer outages, highlighting *"Waived After-Hours / Emergency Fees"* on the VIP tier directly addresses the pain point of expensive weekend calls.
